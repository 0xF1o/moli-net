# Examples

Run any sample from the repository root. No `playwright install` or Chrome download needed.

| Project | Description | Run |
| --- | --- | --- |
| [Moli.Playwright.Sample](Moli.Playwright.Sample) | Connects Playwright over CDP, fills a textbox and clicks a button offline, printing `Hello, Karl!`. | `dotnet run --project examples/Moli.Playwright.Sample` |
| [Moli.PuppeteerSharp.Sample](Moli.PuppeteerSharp.Sample) | Same scenario using PuppeteerSharp. | `dotnet run --project examples/Moli.PuppeteerSharp.Sample` |
| [Moli.Selenium.Sample](Moli.Selenium.Sample) | Same scenario using Selenium. | `dotnet run --project examples/Moli.Selenium.Sample` |
| [Moli.Pdf.Sample](Moli.Pdf.Sample) | Serves an ASP.NET Core page on `http://127.0.0.1:5187`, captures the rendered HTML in middleware, and returns it as a PDF. | `dotnet run --project examples/Moli.Pdf.Sample` |
